# PhotoEditor for Android

The same editor as the web version, packaged as an Android app with
[Capacitor](https://capacitorjs.com). There is no server on the phone: the
editing that `editor.py` does with Pillow is ported to JavaScript
(`src/engine.js`, run in a Web Worker), so the app works offline.

## Get the APK

Every push that touches the app runs the **Android APK** workflow in GitHub
Actions. Open the run, scroll to **Artifacts** and download
`PhotoEditor-debug-apk` (a zip with `app-debug.apk` inside). Copy the APK to
the phone and open it; Android asks you to allow installing apps from that
source the first time.

Each build is signed with a new debug key, so uninstall the old app before
installing a newer build.

## How it fits together

- `scripts/build-web.mjs` builds `www/` from the web version (`../templates/index.html`,
  `../static/*`) plus the files in `src/`. Changes to the web page come along automatically.
- `src/mobile.js` answers the page's `/api/...` requests locally with `src/engine.js`,
  saves to `Documents/PhotoEditor`, adds a Share button, pinch zoom and the back button.
- `src/engine.js` is the port of `editor.py`. A change to the Python editing code needs
  the same change here.
- `android/` is the native Android project generated by Capacitor.

## Build it yourself

Needs Node 22, Java 21 and the Android SDK (Android Studio installs it).

    cd android
    npm ci
    npm run apk        # -> android/app/build/outputs/apk/debug/app-debug.apk

`npm run build` only rebuilds `www/`, which you can open in a browser
(`python -m http.server -d www`) to try the app on a computer.
